# Password Guard

Password Guard is a Python-based cybersecurity web application designed to help users improve password safety and understand common online security risks.

## Features

### 1. Password Analyzer
Evaluates password strength and provides a score and suggestions to help users create stronger passwords.

### 2. Phishing Message Checker
Checks messages for common phishing warning signs, such as urgent requests and suspicious requests for account information.

### 3. Security Risk Assessment
Asks users questions about their security habits and provides recommendations based on their answers.

### 4. Cyber Incident Guide
Provides safety steps for situations such as suspected account hacking, clicking suspicious links, sharing passwords or OTPs, and suspected online scams.

## Technologies Used

- Python — application logic
- Streamlit — web interface
- Visual Studio Code — development environment
- Git and GitHub — version control and project hosting

## How to Run

1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Install Streamlit:

   ```bash
   python3 -m pip install streamlit
   ```

4. Start the application:

   ```bash
   python3 -m streamlit run app.py
   ```

5. Open the local URL shown in the terminal, usually `http://localhost:8501`.

## Limitations

Password Guard is an educational cybersecurity project. Its phishing checker uses predefined warning signs and cannot detect every scam. Its password score is an estimate, not a guarantee of security. The incident guide provides general advice and does not replace professional support.

## Project Purpose

The purpose of Password Guard is to raise awareness about password security, phishing, safe online habits, and appropriate responses to common cyber incidents.
